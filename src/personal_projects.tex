\cvitem
    {\textbf{Pomodoro Timer}}
    {\! %
    \langen{%
        Design and implementation in C of a Pomodoro Timer using
        ATmega328p/STM32F401RCT6 microcontrollers and an SSD1306 OLED display. The
        driver for handling the display and microcontroller peripherals was written
        from scratch.
    }%
    \langit{%
        Progettazione e implementazione in C di un Pomodoro Timer utilizzando i
        microcontrollori ATmega328p/STM32F401RCT6 e il display OLED SSD1306. Il
        driver per la gestione del display e delle periferiche dei
        microcontrollori sono stati scritti da zero.
    }%
    \footnotesize \newline
    [ \url{https://github.com/its-fonsy/avr-pomodoro} ]
    \hfill [ \url{https://github.com/its-fonsy/stm32-pomodoro} ]%
    }
